# Rurutia 模块指引（bug 排查地图）

> 出 bug 先查这张表：按症状找到第一落点文件，再看「模块清单」了解它的邻居。
> 维护约定：新增模块 / 大改职责时同步更新本文件；行号会漂移，所以这里只给函数名和 grep 关键词。

## 二、模块清单（按层）

**服务端（Node，web 版与桌面版共用）**
- `server.js` — 唯一后端：静态服务 `public/`、全部 `/api/*`（文件、搜索、git、终端路径定位、用量、观察舱 token）。端口 4567，被占自动顺延，真实端口在 `global.__rurutiaPort`。

**Electron 主进程（`electron/`）**
- `main.js` — 窗口创建（`hiddenInset` 无框）、原生菜单、`pty:*` 终端、`win:*` 窗口通道（focus / traffic / drag 兜底）、`update:*`、生命周期（红叉只藏、⌘Q 确认、activate 提层）。
- `preload.js` — contextBridge 全家：`fanboxPty / fanboxEnv / fanboxPrompt / fanboxRec / fanboxFs / fanboxClipboard / fanboxDrop / fanboxWechat / fanboxWinDrag`…；顶部 `--rurutia-pv` 早退让预览窗零桥。
- `pv-window.js` — 独立预览窗（Rurutia 新增）：`pv:open` 弹窗、位置记忆、`raise()` 提层。
- `shot-hotkey.js` — 截图直通热键（Rurutia 新增）。
- `starship-config.js` — 终端提示符注入（Rurutia 新增）。
- `wechat/` — 微信 ClawBot 桥。

**渲染层核心（`public/`）**
- `app.js` — 上游主体 + fork 改动（用量、终端链接、标签拖拽等）。⚠️ 文件含 NUL 字节，搜索要用 `grep -a`。
- `index.html` — 装载顺序：vendor → i18n → app.js → 各 patch（themes → prompt → shot → pv → observer → toolbar → drag）。

**渲染层补丁（Rurutia 新增，每个自包含可整删）**
- `themes-patch.js`（皮肤）· `prompt-patch.js`（提示符选择器）· `shot-patch.js`（截图直通）· `pv-patch.js`（独立预览）· `observer-patch.js`（观察舱）· `toolbar-patch.js`（工具条折叠）· `drag-patch.js`（拖拽兜底）。

**样式层（加载序：style.css → ui-patch.css → soft-patch.css，后者胜）**
- `style.css` — 上游原样式。
- `ui-patch.css` — 第一层视觉改造 + 字体 + 全局字体兜底。
- `soft-patch.css` — 「柔和座舱」第二层视觉 + 拖拽区声明。

**其它**
- `vendor/starship` — starship 二进制（extraResources → `Resources/starship`）。
- `build/` — 图标、entitlements、公证脚本。
- `rurutia.patch` / `update-from-upstream.sh` / `RURUTIA-PATCH.md` — 上游同步三件套（仓库治理，不进包）。
- `design-demos/`、`experiments/`、`docs/` — 样例、实验、文档（不进包）。

## 三、查案惯例

- **分叉文件搜索用 `grep -a`**：`app.js`、i18n 词典等含 NUL 字节，普通 grep 会当二进制静默不匹配。
- **web 版 vs 桌面版**：渲染层以 `window.fanboxPty` / `fanboxEnv` 判环境；web 版没有任何 `fanbox*` 桥，所有桌面功能要能零桥降级。
- **补丁隔离**：改上游文件尽量“在原函数里插段”，新能力开新 `*-patch` 文件——上游 re-sync 时 A 表（新增文件）永不冲突。
- **验证路径**：UI 改动用无头 Chrome 截图核对；服务端改动起 `FANBOX_PORT=<测试端口> node server.js` 直接 curl；Electron 改动可写最小 harness 用真 preload + 真补丁文件跑合成事件（参考 v2.13.2 拖拽兜底的验证）。
